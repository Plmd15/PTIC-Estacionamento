# 🚘 Garagem de Carro — Gestão de Estacionamentos

## 📌 Visão Geral do Projeto

O **Garagem de Carro** consiste numa proposta de prototipagem de alta fidelidade focada na administração e organização de um estacionamento, desenvolvida como projeto pedagógico.

A aplicação simula uma interface completa para otimizar o fluxo de veículos, o registo de utilizadores, a alocação de lugares e a gestão do pessoal, garantindo um acompanhamento preciso de entradas e saídas.

## 🎯 Principais Objetivos

* Criar uma maquete funcional e visual para um sistema de estacionamento.
* Agrupar os recursos fundamentais num painel simples e de fácil utilização.
* Melhorar o controlo e a visualização em tempo real das vagas disponíveis.
* Mapear com clareza o ciclo de entrada e checkout dos automóveis.
* Testar a usabilidade da plataforma antes do processo de desenvolvimento.

## 🛠️ Recursos Representados

* 🔒 **Acesso:** ecrã de autenticação e início de sessão no sistema.
* 🖥️ **Painel de Controlo:** ecrã principal com métricas resumidas da operação.
* 📥 **Registo de Entrada:** formulário para dar entrada aos veículos no espaço.
* 📤 **Registo de Saída:** consulta de histórico para validação e libertação do veículo.
* 👤 **Base de Clientes:** formulário para gestão e consulta de condutores.
* 📈 **Relatórios:** análise de dados, métricas de ocupação e movimentos.
* 💼 **Gestão de Operadores:** ecrã para criar e gerir contas de funcionários.
* 🅿️ **Mapa de Vagas:** esquema gráfico que mostra os lugares livres e ocupados.

## 🎨 Tipo de Projeto

**Protótipo Visual de Alta Fidelidade:** modelo interativo detalhado que antecipa a aparência, o layout e a navegação do sistema antes do desenvolvimento de código.

## 🧰 Tecnologias de Suporte

* **Canva:** utilizado na construção e estilização das interfaces gráficas.
* **Google Docs:** utilizado na documentação dos fluxos e requisitos.

## 🎓 Propósito Académico

Este trabalho foi elaborado estritamente para fins educacionais, focando-se na arquitetura de informação, no design de interface e na organização funcional de software.
